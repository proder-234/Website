Nepali people deserve a weather app that provides them exact weather information provided by the government. Space Invaders 2026
5 threads, 60 Hz collision, 2 game modes, OOP assignment.
What I focused on

The course asked for a basic game but I wanted to do more. I tried to understand what multithreading synchronization actually looks like under load and designed a 5-thread architecture where each subsystem runs at its own Hz.

Problem · Solution · Impact
  • AWT event thread conflicting with game threads caused race conditions on shared entity lists
  • Introduced ReadWriteLock + volatile variables + CopyOnWriteArrayList; ActorUpdate at 50 Hz, Collision at 60 Hz, UI at 33 Hz
  • Zero race conditions; smooth dual-mode gameplay with power-ups, shields, high-score persistence
Tech Stack
Java Swing / AWT ReadWriteLock Exception Handling SRP / OCP I/O persistence

SearchWave
Dual-mode search engine. Zero backend. 10k+ songs ranked in the browser.
What I focused on

A Data Mining and Information Retrieval course assignment about data retrieval. I pushed it into a real deployed search engine with live web results via DuckDuckGo proxy HTML parsing, plus an in-browser lyrics IR engine that scores 10k+ songs entirely client-side.
